# macOS local test package

`python3 scripts/package_macos.py` packages the release binary from `cargo build --release -p easycat-app` and the installed FFmpeg tools into a self-contained native macOS application and compressed DMG. The published builds require macOS 15 or later, derived from the minimum deployment versions of the included Mach-O binaries.

The application launcher uses the bundled Helpers directory, independent of the Finder PATH. Non-system dynamic libraries are copied recursively into Frameworks and relinked through loader-relative paths. SDL3 is included from the active Homebrew prefix for the SDL2 compatibility layer used by ffplay. The source binaries' SHA-256 hashes, package receipts, formula metadata, available license files and SBOMs are preserved under Contents/Resources. The packaging script verifies no non-system absolute dependencies remain and applies an ad-hoc signature to the bundle and each executable/library.

The DMG contains easycat.app, an Applications shortcut and English installation notes. Drag the app into Applications to install. There is no Developer ID certificate or notarization for this local build. Public distribution review, complete source-offer obligations for third-party components and release notarization are not completed by this script. Do not treat this local test artifact as an approved public release.

The staging directory is `target/macos-package`; an existing staging app or output DMG is intentionally not overwritten. Rename previous generated artifacts before packaging another build. System disk-image services may require execution outside a restricted sandbox.

Verification performed: strict recursive code-signature verification; a generated 0.3-second H.264/AAC clip encoded and probed using bundled executables with a system-only PATH; audio playback using bundled ffplay with dummy SDL audio/video drivers; disk-image verification. The script packages the host architecture: `arm64` for Apple Silicon or `x86_64` for Intel. Every executable/library must contain that architecture; mixed bundles are rejected. DMG names include the architecture. Intel builds run natively on the `macos-15-intel` GitHub runner using `.github/workflows/macos-intel-package.yml`, with native Rust tests, generated-media codec/export checks, packaged GUI startup, strict signature and DMG verification. These are separate architecture-specific packages, not a universal build.

The app now uses the pink cat mascot icon. Packaging generates all standard ICNS representations from `easycat-app/assets/app-icon.png` and registers `easycat.icns` in the bundle metadata. The same PNG is embedded as the native viewport icon for other platforms. GitHub prerelease files are linked from `DOWNLOADS.md`; availability is listed explicitly for each platform.

The Intel CI job installs FFmpeg and its codec dependencies through the pinned recipes in `distribution/compliance/intel-formulae`. These preserve the existing upstream source URLs, checksums and build instructions, adding `env :std`, portable CPU flags, SDK header ordering, explicit dependency paths, diagnostic logs and local-tap maintenance metadata so the job can use hosted CMake/Python and an isolated Meson 1.12.1 environment. When Intel bottles are unavailable, Homebrew builds them from source; the first run can take substantially longer than an Apple Silicon build. The final DMG is self-contained and does not require Homebrew on the user's Mac.

The Intel FFmpeg build restricts pkg-config, compiler and linker searches to the pinned runtime libraries and disables unused X11 capture. A changed FFmpeg recipe invalidates its cached build. Native package verification rejects dependencies outside the reviewed source inventory before the package can pass.
