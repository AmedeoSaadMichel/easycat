# Standard license texts

These canonical texts come from the SPDX license list:

- https://spdx.org/licenses/MIT.html
- https://spdx.org/licenses/CC0-1.0.html

They supplement the explicit license declarations in the published crate metadata listed in `metadata-only-crate-licenses.json`. They are not fabricated upstream license files or a new license grant by easycat. The MIT copyright placeholder is part of the canonical template; actual package authors are recorded in the metadata report. Preserve any original copyright and license notices in the complete crate sources. Review this exceptional metadata-only evidence before public release.
